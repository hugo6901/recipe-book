# 내 레시피

폰에서 보는 개인 레시피북. 서버·DB 없이 파일 2개로 돌아간다.

- `recipes.md` — 레시피 전부. **여기만 고치면 된다.**
- `index.html` — 보는 화면. 건드릴 일 거의 없음.

## 레시피 추가하는 법

GitHub에서 `recipes.md` 열고 연필 아이콘 → 맨 아래에 아래 형식대로 붙여넣고 저장.
1분쯤 뒤 폰에서 새로고침하면 나온다.

```markdown
---

# 레시피 이름
태그: 찌개, 간단
시간: 30분

## 재료
- 재료 1
- 재료 2

## 순서
1. 첫 번째
2. 두 번째

메모: 아무 말이나
```

## 규칙 4개

- 레시피 사이는 `---` 한 줄로 구분 (새 레시피 위에 꼭 넣기)
- `# 제목` 은 필수, `태그:` `시간:` 은 있으면 좋고 없어도 됨
- `## 재료` / `## 순서` 이 두 개만 화면이 특별 취급
- `메모:` `참고:` `출처:` `팁:` 으로 시작하는 줄은 어디 있든 맨 아래 메모칸으로 빠짐

## PC에서 확인

`index.html` 더블클릭하면 안 된다(브라우저 보안에 막힘). 이 폴더에서:

```bash
python -m http.server 8000
```

→ `localhost:8000`

## 나중에

레시피가 100개쯤 넘어 파일 하나가 답답해지면, 레시피 1개 = 파일 1개로 쪼개고
목록 만들어주는 스크립트를 붙인다. 화면 코드는 거의 그대로 쓴다.
